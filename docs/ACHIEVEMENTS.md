# Achievements and Sparkling dex tiers

## Requirements and scope

The current catalog has 79 achievements. Names and descriptions below are the intended requirements. Personal catches remain personal for achievements saying yourself/your own, First Sparkling, Back to Back and Instant Gratification. Party sparkling catches are credited for duplicate streaks and all dex tiers. Repeated sparkling catches count as duplicates until a new unique type resets the streak; the milestone uses the longest recorded duplicate streak, not a number of runs.

Daily achievements count only runs strictly longer than 120,000 ms, grouped by their local completion date. Exactly 2:00 does not count. Existing history exclusion of over-30-minute rows still applies. Speedrunner/Any%/G.O.A.T stop at the 37th type caught or loot-shared, strictly before 2:30/2:00/1:30. Instant Gratification measures at most five run positions between personal sparkling catches, including an active run and a second catch in the same run; ticket quantities do not determine it.

Macaw drought counts only consecutive zero-Macaw runs with explicit saved proof that all nine floor-food opportunities plus known personal starting food produced birds, no food remains in inventory or the feeder, and no Macaw was spawned/rendered/caught. A party report alone cannot establish this. An unknown/unqualified run breaks the streak. Older rows lacking the new allBirdFoodUsed/macawsSeen evidence cannot earn drought achievements retroactively.

Emerald Dye milestones use persisted personal drop counts. Drop/broadcast pairs are deduplicated without dropping separate rapid finds. An old Emerald Dye achievement establishes one confirmed dye; additional unlogged historical dyes cannot be invented. Contest totals retain the selected-ticket target: Uncommon for Basic and Legendary for First-Class. Coin achievements use the existing recorded reward/profit values; catches include recorded loot shares, with existing cached profile totals as a floor.

## Dex Type selector

History → Sparklings has a Dex Type dropdown from Sparkling dex (1x) through Dupedex, Tripdex, Quaddex, Quindex, Sexdex (nice), Septdex, Octodex, Nuevadex and Decadex (10x). A type is colored only when its credited catch count meets the selected threshold. Biome and total completion counts follow that threshold. The Mine only filter affects the catch list, not credited dex totals. Hovering a dex species shows its count.

Saved/imported credited party catches supply per-species counts. Existing cached API discoveries establish at least one catch but cannot establish higher per-species multiplicity. No new API request is made for the dropdown or achievements.

## Migration and hover text

Achievement catalog version 2 backs up the prior achievement file before rechecking changed requirements. Stable IDs preserve unchanged valid unlocks; changed thresholds/units are removed and re-evaluated quietly from retained records, saved counters and existing cached profile data. Run/sparkling histories and PBs are not reset. Secret status applies to CJ Luck, This Is Water… Use It., and Double Trouble.

Explanatory hover prose is removed except the Macaw drought note: Must use all 9 bird food. Standard rarity, description and progress UI remain.
