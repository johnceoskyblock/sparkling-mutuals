## Rule ownership and navigation

[Exact messages](MESSAGES.md) own quotations and their event meanings; [floor drops](FLOOR_DROPS.md) own resource prediction; [bird completion](../BIRD_COMPLETION.md) owns the three bird species' shared source proof. [Missing panel](../MISSING_PANEL.md) separates progress, rows and helpers. The [audit](../IMPLEMENTATION_AUDIT.md) records unresolved discrepancies and server uncertainties.

The four fixed check targets are Scrappy 3, Gemzie 3, Troodon 3 and Gazer 4. Other roster numbers are implemented minima, not evidence that all opportunities were observed. Capture, checking and display are separate outcomes. Detecting a Sparkling does not itself add a completion blocker.
