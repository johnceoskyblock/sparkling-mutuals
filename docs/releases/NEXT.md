## What’s New in 5.0.1

### All editions

- Doomspiral, Wumpa, and Gemzie checks count from verified Main-server announcements even without a Safari ticket. Each Gemzie chamber opening counts as three Gemzies, including openings already saved in history.
- `!doom`, `!wumpa`, and `!gemzie` replies use regular plurals without apostrophes.
- Fixed party-sync reconnects after a party expansion that could stop Safari progress updates.
- Critterdex uses rarity colors for found Sparklings and a single **Close** button to return to Sparklings.

### Full editions

- Fixed shared Sparkling alerts stopping after reconnecting with an expanded party.

## Downloads

GitHub releases provide all three builds for Minecraft **26.1.2**, **26.2**, and **26.3**. The release workflow also publishes the verified **Standard** builds to Modrinth, one version per Minecraft target. Install one JAR with the matching `+mc` suffix.

| Edition | Filename suffix before `+mc` | Updates |
| --- | --- | --- |
| **Standard** | None | Manual downloads |
| **Full** | `-full` | Verified in-game downloads with a configurable Auto Update toggle |
| **Full No Auto Update** | `-full-no-auto-update` | Manual downloads |
