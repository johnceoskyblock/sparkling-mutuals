# Sparkling Mutuals

A Fabric client mod for Hypixel SkyBlock’s Critter Safari.

## Installation

1. Set up **Minecraft 26.1.2, 26.2, or 26.3** with **Java 25** and [Fabric Loader](https://fabricmc.net/use/installer/) **0.19.5 or newer**.
2. Put [Fabric API](https://modrinth.com/mod/fabric-api) for your Minecraft version and [Fabric Language Kotlin](https://modrinth.com/mod/fabric-language-kotlin) in your `mods` folder.
3. Download Sparkling Mutuals from [GitHub Releases](https://github.com/johnceoskyblock/sparkling-mutuals/releases/latest). Pick the JAR whose `+mc` suffix matches your Minecraft version, put it in `mods`, and remove any older Sparkling Mutuals JAR.
4. Launch the Fabric profile and use `/sm` to open settings.

## Features

| Feature | What it does |
| --- | --- |
| Safari modes | Track Sparkling checks, one catch per species, or a Full Clear with `/sparkle`, `/unique`, or `/fc`. |
| Safari HUD and highlights | See progress, remaining objectives, critters, floor drops, bee nests, and other spawn sources. Clear water improves underwater visibility in Safari. |
| Sparkling alerts and lookups | Highlight detected Sparklings, compare party discoveries with `/sparkling`, and see rate estimates with `/rates`. |
| Capture helpers | Preview estimated capsule paths and landing points, and select the matching hotbar gem at Gemzie podiums. |
| Party coordination | [Share Safari objectives and Hotspot assignments](docs/PARTY_SYNC.md) with compatible SafariUtils parties. Manage downtime, entry readiness, and timed Sparkle Warping. |
| Sparkling auto entry | Opt in to joining a party member’s Safari when shared sync reports an outstanding Sparkling. |
| Miria contests and Honeyhives | Track contest progress and ticket readiness, and see Honeyhive locations and refill timers. |
| History and achievements | Review runs, catches, personal bests, achievements, and profit. Open `/sm history` to view history and import older runs from Minecraft logs. |
| Hunting Box and Bazaar | Estimate Hunting Box value, view experimental shard and Safari Essence sale guidance, and rank critters by ticket type with `/profit`. |
| Other SkyBlock helpers | Garden Phantomleaf Solver and Skills overflow tooltips. |
| Customization | Move and resize HUDs with `/sm gui`, and customize highlights, banners, alerts, and catch effects in settings. |
